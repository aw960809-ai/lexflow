# LexFlow V0.4｜官方答案表位置式核對（仍未核驗，不計分）

## 目的與既有功能

不另建題庫與法律科目專用工作台。僅在現有 `moex_quality_overlay.py` 中補入「同一 PDF 頁面上、題號表格與答案表格位置」的逐欄核對。原始 Q/S/M PDF、原報告及原始試卷身分不更動，結果輸出到獨立的 `quality_previews/`，不存入正式題庫。原有資料仍以完整試卷為單位。

## 此次修正

- 使用 pypdf `visitor_text` 取得表格中題號及答案的視覺位置，要求同頁題號列與答案列、欄位中心及題號連續性相符。**禁止根據 PDF 純文字擷取順序自行補齊答案**。
- 遇到答案缺格、列移位、超出題數、題號重複、前後解析矛盾、舊答案候選不符，清楚保留異常資訊，不宣稱配對完成。
- M 更正答案有 `#` 時，先視作「更正標記」而非選項。只有明文備註（例：第 20 題 B 或 C 者均給分）才保留兩個**候審**選項，絕不縮減為一個正式答案。
- 與原本試卷已擷取的答案候選再次核對，不一致時清空本次新表格候選，保留舊資料供人工審查。
- `publication_allowed=false`、`scoring_enabled=false`、`final_answers_verified=false` 永久保留；不得使用這次修正當成正式閱卷或正式題庫。

## 測試及現實限制

在合成表格 PDF（**絕非考選部原卷、非真實答案**）測試：S 題型可取得 30 個單選候選；M 題型取得 49 個單選候選加第 20 題 B/C 特殊給分，保留共 50 題覆蓋。測試亦包含錯位、缺格、重複表、來源篡改、與舊候選衝突。

上傳的三份 `quality_previews` 未附官方 PDF 原始位元組；因此尚未在此開發環境對手機快取中**真實** M/S PDF 執行新程式。需在原有 Termux `official_pdf_cache` 重新驗收，通過才可推送 Draft PR。若現實 PDF 版面仍無法安全對位，程式應明確拒絕並留下候審診斷，**不可推送為已完成**。

## 正式網站與紀錄保護

僅更新 `feat/v03-moex-official-index-20261008` Draft PR。未經使用者核准不合併 `main`、不強制推送、不清理 `localStorage`、不向公開 GitHub 提交原始 PDF 或私人作答。GitHub CI 的 PDF smoke job 只使用合成 PDF 測試表格，不驗證私有手機環境中的來源快取。
