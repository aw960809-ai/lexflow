# LexFlow V0.3 — 考選部官方試卷候審索引

**目前定位**：功能開發候審，非正式國考題庫。既有 V0.2 正式網站及使用者個人資料不受本次試驗影響。

## 資料來源
- 考選部資料開放：<https://data.gov.tw/dataset/170565>
- 官方 CSV：<https://wwwc.moex.gov.tw/main/Exam/wHandExamQandA_CSV.ashx>
- 下載不成功或格式不正確時：停止、保留舊索引，不顯示「沒有題目」。

## 功能與信任界線
1. 定期尋找考選部所公布的試卷及答案文件連結。
2. 以科目名稱初步選取民法、刑法、憲法；綜合法學與法學知識列為混合／待分類。
3. 同一考試同一 PDF 出現在多個類科時，將類科合併避免重複計數。
4. 把原題或答案文件的 URL 記錄為**未核驗連結**；此階段不拆 PDF、不識別正確選項、不產生法律詳解，也不更動 `quiz.js` 的答案。
5. GitHub Actions 會定期拉取官方 CSV；候審索引透過 GitHub Draft PR／PR 提案，不會直接合併 `main`。若 GitHub 拒絕 PR 權限，下載的 artifact 保留可供人工核對。
6. 原本申論紀錄、草稿、計時、JSON 備份都只在前端原有儲存機制，更新器不能接觸其內容。

## 可靠性
- 網址只允許 `moex.gov.tw` 與其子網域，防止外站偽造官方答案。
- CSV HTML 錯頁、缺欄、意外空資料、來源不可用皆 fail-closed。
- 沒有題目數量的事實證據時，UI 明確顯示**尚未同步**，不會說「本次沒有題目」。
- 官方試卷類型用原資料標示，混合科目不能冒充純民法／純刑法／純憲法。
- 自動審核通過只表示來源結構合格，**不代表答案或詳解 100% 正確**。
