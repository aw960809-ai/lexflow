# LexFlow V0.3｜統一題庫及操作驗收（Draft PR）

狀態：**僅於 PR #1 開發分支候審；不可自動合併 `main`**。本輪停止 PDF 解析器精修，重點放在一個使用者真正找得到的題庫入口與可安全保存的作答流程。

## 統一入口

- 主系統原有「題庫」分頁，預設改顯示一個完整清單，統一提供「科目／題型／來源／關鍵字」篩選。
- **自編申論／個人自建申論**：進入原 V0.2 申論編輯器，支援計時、存稿、既有紀錄。
- **考選部官方申論原卷**：保留原 PDF 連結；必須自行選取原卷題目後作答，未聲稱完整題文已匯入。
- **自編選擇題**：可從統一題庫開啟 V0.2 單題詳解，也可到 V0.3 學習室做六題連續練習；分數僅屬自編教材參考。
- **官方選擇題候審**：只有該網站的學習室已匯入合法候審 JSON 才顯示可練習試卷。選擇試卷可連至學習室相應試卷，仍需使用者明確點「開始私人自測」。不會顯示答對答錯或產生國考分數。
- 曾在單檔 `content://` 預覽中匯入或作答的候審資料**不會自動同步**至 GitHub Pages。需要自行匯出／匯入對應版本備份，不得默默複製或覆寫。
- 原有「申論編輯器」「自編單題」仍以次要模式保留，避免既有使用流程被移除。

## 手機版操作精簡

- 將官方候審練習的題號導覽縮為可展開區塊，避免 25 個按鈕長期佔滿手機高度。
- 考試名稱詳情可以展開查看；主標題保留科目與資料來源。
- 結果統計壓縮，備份入口改為次要操作，同時保留官方候審「不計分」與「非對錯判定」提示。

## 資料安全與計時

- V0.2 的 `lexflow-data-v02` 與學習室的 `lexflow-v03-practice-lab-v1` 仍分開儲存。
- 統一題庫對學習室僅唯讀取得試卷**標題和題數**；不讀取、展示、合併私人答案紀錄。
- 正在進行的學習室計時每約 10 秒保存一次快照；切換背景時暫停、重新開啟後保持暫停，避免將離線時間計入作答。
- 完成練習若寫入失敗，不應假裝已保存；資料毀損時保持唯讀並提供匯出備份的機會。
- 學習室 JSON 備份與還原只影響 V0.3 的私有學習室資料，**不覆寫 V0.2 紀錄**。

## 驗收與已知限制

- GitHub 固定 CI 執行原 Python 法律來源測試，以及 Node `catalog-core`／`practice-core` 安全單元測試，另檢查 JavaScript 語法。
- 本地以 Chromium 離線 DOM 模擬測試統一篩選、V0.2 舊介面、自編單題、官方候審匯入、練習續作、結果、備份還原與資料損壞保護。由於本執行環境限制 localhost 網路，**不應將此測試稱作真實 HTTP 或 PWA 更新測試**。
- 發布前仍需在 Android Chrome／PWA 上測試更新後的實際網站、跨頁導覽、Service Worker 更新，以及使用者自己的備份匯出／還原。
- 官方候審題內容、最終答案及更正未完成逐題人工核對；不得藉由介面整合繞過現有 release gate。正式 `main` 繼續維持 V0.2。
