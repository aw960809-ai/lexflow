# LexFlow V0.3｜第一個可實際操作的學習室（Draft PR 專用）

狀態：**開發版；尚未合併 main 或正式發布。** 本版本刻意停止針對少數 PDF 反覆修正解析器，把既有成果接入可操作的手機學習介面。

## 如何使用

在 LexFlow 的「題庫」頁，從申論題庫或選擇題庫入口開啟「V0.3 多題練習室」；或者使用相同目錄下 `practice-lab.html`。

- **自編法條示範題**：使用 `quiz.js` 原有 6 道自編題，可連續作答，查看自編正解、逐選項說明與法務部全國法規資料庫法條連結。這不是考選部題目，完成後的成績不能被稱作國考分數。
- **官方候審題私人練習**：使用檔案輸入，於本機匯入 GitHub Actions 的 `moex-cross-field-UNVERIFIED-batch-review` 裡 `lexflow-universal-batch-UNVERIFIED.json`。頁面僅顯示拆出四個非空選項的候審片段。未完成拆解的題目繼續隔離。
- 在官方候審模式下，可以逐題自選 A～D、跳題、標記、暫停計時、儲存／重整後續作、結束後比較「自己的選擇」與「公布答案的未核驗擷取值」，**不顯示答對率、正確題數或國考分數**。
- 可匯出／重新匯入學習室私人備份。匯入備份會在明確確認後覆蓋**學習室自身**的資料，絕不覆蓋 V0.2 的儲存鍵。

## 關鍵資料保護

- 主程式 V0.2 原本儲存鍵 `lexflow-data-v02` 維持原樣；學習室另用 `lexflow-v03-practice-lab-v1`。不會讀取、合併、上傳原有的作答、草稿、記錄或完整私人備份。
- 官方候審 JSON **不提交到 GitHub 原始碼庫、不發布成正式題庫**。使用者自行於本機檔案匯入，字串均經 HTML 跳脫；來源連結只接受 HTTPS 考選部網域。
- 官方原卷資料來源為考選部候審索引及 PDF 擷取；即使題文四個選項完整，仍未完成逐字對照影像、最終更正或特殊給分的人工核對，也不保證跨頁或特殊排版完全正確。使用者應開啟原卷逐題對照。
- 載入錯誤或未確認 `publication_allowed=false`、`scoring_enabled=false` 的候審資料，一律拒絕。答案 PDF 與試題的 Q／S 配對未確證時，不提供候審答案字母。
- 腳本與介面沒有執行任何正式國考題目的自動給分或 AI 法律批改。自編題評分僅為自編教材自測。
- 本機資料若不能解析或無法可靠寫入，系統保留原始 bytes 並停止覆寫；主程式原有資料不受影響。

## 為何仍維持 Draft PR

此版本證明可操作的 UI、學習進度與候審來源隔離，而不是證明逐題內容或法律詳解已通過核驗。正式發布前仍須驗證真實手機 PWA、正確樣本、資料備份，以及至少一批經人工逐字核對的官方題目與最終答案；不可誤以本地測試的成功代表法律正確性。

## 驗收

- Node：`node --test tests/practice-core.test.mjs`（偽造評分狀態、惡意網址、重複題號、備份版本及官方題零分數等）。
- Chromium 本機回歸：多題作答、重新載入續作、標記、結果、自編法源解析、匯入真實候審 JSON、備份、壞檔只讀、手機沒有橫向溢出。
- V0.2 原有手機／桌面、申論／選擇、草稿、紀錄、備份與原官方候審索引瀏覽器回歸測試仍須通過。
- 新增靜態檔案只在 PR 開發分支；GitHub Pages 的 `main` 保留 V0.2。
