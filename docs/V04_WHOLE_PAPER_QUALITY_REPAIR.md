# LexFlow V0.4｜整卷解析品質修正（保留人工候審）

這是 **原有 V0.4 目錄橋接程序的增量修正**，不是按個別法律科目另建題庫。以官方整份試卷為單位，保留考試、年度、等別、類科、原始科目名稱、官方題型及 Q/S/M 連結。所有卷內題目均是 **同一原始試卷的索引**，不能被拆為獨立官方試卷。

## 修正範圍

1. 中文行首「一、二、三、四、」可接中文字句，要求從一開始完整且遞增的序號；仍需與 PDF 逐頁核對。
2. 只有明確成對的官方 `代號：...` + `頁次：總頁數－當前頁` 會作為頁框候選清理，不任意刪除疑似相似字串；保留原始 PDF、舊報告與原文，新增獨立的候審影本。
3. M 更正答案 PDF 若具有可可靠對位的題號與答案表，嘗試建立 **未核驗的答案候選**，並保留「B 或 C 均給分」等多重給分候選；不宣稱已核定更正／正式計分。缺少官方 PDF bytes 或 SHA256 不符則直接保留待審。
4. 科目名稱僅比對時使用 NFKC，不改動考選部原本的科目標題。
5. 混合題辨識「甲、作文部分／乙、測驗題部分」等卷內分段，作文不會變成「法律申論」，整卷 ID 不變。

## 真實驗證與限制

由使用者提供的 `LexFlow_V04_3papers_review.tar.gz`（只有報告與 Q 文字、**不包含原始 Q/S/M PDF 快取**）作離線重播：

- 114 初等法學大意：50／50 題選項候選；**M PDF 的實際答案表還需使用手機既有來源快取確認**。
- 113 關務三等行政法：4／4 道申論大題索引。
- 114 身障三等基礎能力測驗：作文與測驗兩區段、30／30 題四選項候選；原本第 1、8、13、19、25 題受到頁框污染，現在可安全產生新候審影本。

驗證結果都是 **source preview NEEDS VISUAL REVIEW**，沒有任何一題經人工核准計分。原始 Q/S/M PDF 不在分享的 tar 檔內，無法聲稱 M 表格或逐字內容已通過官方實卷核對。本次只修安全候審管線；正式題庫發布、AI 生成申論擬答與完整人工檢核是不同步驟。

## 安全及可重現使用方式

```bash
python scripts/moex_quality_overlay.py --review-dir "$HOME/lexflow-v04-catalog-review/official-review"
```

它只讀取 `reports/`、`extracted_text/` 及 `official_pdf_cache/` 已存在的公開來源資料，對每份試卷產生 `quality_previews/<paper-id>-<fingerprint>.json`。相同資料重跑不覆寫，來源指紋改變另產候審檔。**不發送網路請求、不讀取私人作答、不改 V0.2/V0.3 儲存鍵，也不提交公開原題全文。** 未取得的更正答案永遠保持待核驗。

`moex_catalog_bridge.py` 已有整卷 `plan`／`review` 流程；修正後的 `review` 只是在原始下載及驗證後額外產生獨立品質候審檔，舊報告一律保留。
