# LexFlow V0.3｜跨科答案表、頁面邊界與發布前驗收（開發候審）

**實作範圍**：開發分支 Draft PR #1。所有解析結果必須維持 `publication_allowed=false`、`scoring_enabled=false`。絕不修改 V0.2 正式 `main`、`quiz.js`、`data.js`、本機作答紀錄與使用者備份。

## 現實問題：完整 25 題，但答案表有空白樣板欄

考選部 114 年司法特考四等「民法概要」官方標準答案 PDF，是每一列 10 格、第三列 21–30 題，實際只有 21–25 題有填答案的**固定樣板**。不可將該列「五個 A/B/C/D」硬套到任意五個格，也不可因總表使用 100 題樣板就推論 100 題已作答。

此版新增 **PDF 頁面儲存格位置證據** (`pypdf` visitor)：必須每個 `第N題` 及 `A/B/C/D` 文字有明確位置，題號儲存格沿 X 軸連續、答案緊鄰正下方、每格唯一且無中間缺值；最後一列未作答欄位必須全部在官方聲明題數之外。與原本的文字表格對讀有衝突時，**整份答案仍拒絕配對**。多欄合併、影像掃描、字元座標失效或 PDF 版型差異過大都應進入候審。

**重要限制**：本版的版型座標能力已用本機產生的 PDF 及惡意錯欄案例測試，但新程式對**真實考選部 S PDF**的版型適配，必須待新版 GitHub Actions 執行後才能確認。不能事先聲稱已自動比對成功。

## PDF 文字中的跨頁頁碼

若一題的第 D 選項尾端恰有「代號：…／（額外的數字代號列）／頁次：N－M」**完整且精確位於候審題目片段最末端**，可為後續候審選項產生另一份**註明已忽略頁框**的文字。原始 `raw_pdf_excerpt_unverified` 不修改。若頁次之後還有其他正文、引用文字或共享閱讀文章，即不可套用此規則，必須保持隔離。

四選項拆解成功，只表示排版預覽可用；絕非已目視核對的試題文字。

## 公布答案 S 與更正答案 M 永遠分離

- `S`：僅在題號＋官方公布答案有可信且可重現的資料關聯時建立 `published_standard_candidate`，仍是**候審公布值**。
- `M`：只解析官方文件中「備註」欄位的題號及特殊給分文字，建立 `affected_question_numbers_NEEDS_VISUAL_CHECK`、`special_scoring_mentioned` 與備註節錄。未從備註確認的題號絕不從整頁「第N題」樣板猜測。
- 即使 M 說明「第1題答 B 或 C 者均給分」，也不自動改寫 S、不產生已核驗最終答案，並要求人工確認該考試對應文件、發布日期與適用分數。
- 若某試卷沒有 `M` 連結，也**不代表官方從未發布其他更正**；必須核對官方最新公告及有效時點。
- 官方 `A` 全考試總表屬考試層級，不自動套用到個別科目。

## 發布門檻（兩種不同證據）

1. **可作答計分的題庫**：必須逐題對照官方原卷目視核對題幹／全部選項，保存試卷與答案 PDF SHA-256、考試／科目身分，確認官方原始答案及全部更正、複數正解與一律給分、版本及時點，再有人員複核。**只靠程式的 OCR／文字抽取、PDF 能打開、公布答案表並不滿足此門檻。**
2. **可展示的法律詳解**：在上一門檻外，需要獨立查核法條、施行日期、修正沿革與適用之實務見解；考選部給的選擇題標準答案不能直接證明 AI 生成詳解正確。

`moex_release_gate.py` 是**只讀、不授權發布**的稽核報告工具。它會列明每張試卷是否已出現完整候審選項與公布答案，以及仍缺少的「人工比對／最終更正／法律詳解」證據；即使條件在候審報告中看似完整，也一律保持 `score_release_allowed=false`。若有任何夾帶 `eligible_for_scoring=true` 等偽造核准旗標，會直接 `FAIL CLOSED`。未來正式發布須另設明確的人工授權程序，不會隱含在這個候審模組中。

## 固定 GitHub CI

1. 原有 Python 單元測試與前端語法檢查保留；新增 `test_moex_quality_upgrade.py`，包含 10 格＋5 個答案、錯欄、缺中間儲存格、衝突、跨頁污染、特殊給分、惡意計分旗標等反例。
2. 原有 `universal-batch-smoke` 只下載既有批准的最多 3 份、9 次官方文件，不額外增加 PDF 爬取量；在**同一批候審結果**產生 `lexflow-release-readiness-UNVERIFIED.json`。
3. 兩份報告一起保存在 GitHub Actions artifact。沒有在程式碼中寫死「民法概要／2025／2201」的配對器；**但官方個別考試頁探索仍維持上游安全白名單**，沒有宣稱可遍歷所有年度。
4. 任何流程失敗，原始索引與 `main` 完全不變。每批下載受到文件數、時間與網址來源限制。

## 真實驗收仍需確認

- 新版 CI 的 3 個跨科目樣本是否成功，輸出 `candidate_question_pipeline` 數字及錯誤是否受控。
- 官方標準答案 25 題表格若不能產生可信的 X/Y 單元格，就仍記為待人工核對；**不能為了把 0 改成 25 而降低驗證標準**。
- 更正 PDF 備註若提到特殊給分，必須列入人工審查佇列；不能把 S 或 M 任何單一字母當成最終答案。
- 在人工複核完成以前，V0.3 一律不合併為正式計分題庫。Draft PR #1 保留，V0.2 網站及本機紀錄不更動。
