# LexFlow｜法律雙軌申論與國考練習 V0.2 Beta

本版本是獨立、免費、純靜態的 GitHub Pages 測試網站。

## 已有功能

- 3 道自編法律申論練習題、6 個考選部歷屆司法官／律師第二試官方原卷連結。
- 6 道**自編**選擇題，逐選項說明與官方法條連結（**不是**歷屆考題、未經專家完整校準）。
- 申論計時、暫停、自動存稿、結構初檢與歷史紀錄。
- 深色、淺色與跟隨系統主題。
- JSON 匯出／合併匯入。遇到不相容資料或儲存失敗時會提示，不會默默聲稱保存成功。
- 可於支援的瀏覽器中安裝為 PWA，靜態資源可離線使用。

## 尚未建置

- 考選部所有選擇題的自動抓取、官方更正答案比對、歷史法律版本與可信完整詳解。
- 可信的法律實質 AI 批改、正式國考分數估計、手機本機模型連線。
- 自動跨裝置同步；本版資料保留在**當前網站來源的瀏覽器儲存區**。

## 安全與隱私

- GitHub Pages 網站與原始碼公開，**不要把私人作答或匯出的 JSON 備份提交到 GitHub**。
- 目標管理、多益、記帳與 LexFlow 等 `*.github.io` 專案若使用相同帳號的 GitHub Pages，雖然各有不同網站路徑、資料鍵與 Service Worker scope，**仍屬相同瀏覽器 origin，並非嚴格的隱私沙箱**；只應部署可信賴程式碼。
- 清除瀏覽器網站資料或更換來源可能造成記錄不可見或遺失；務必定期自行匯出 JSON 備份。
- 任何法律解題資料均僅供學習參考，需核對最新官方法源。
